# TASK-23
WorkspaceAI – Tailwind Mini Project

Project Description

WorkspaceAI is a responsive workspace landing page built with HTML and Tailwind CSS CDN. It includes a dashboard preview, floating cards, feature sections, pricing plans, testimonials, events and an interactive chat widget.

Features

- Sticky responsive navbar
- Orange gradient hero section
- Dashboard preview and floating cards
- Interactive hover effects and animations
- Responsive feature and gallery grids
- Bento-style values section
- Pricing cards and testimonial section
- Contact call-to-action
- Events section and multi-column footer
- Fixed bottom-right chat widget
